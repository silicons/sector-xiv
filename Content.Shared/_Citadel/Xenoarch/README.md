# Xenoarch

Welcome to sci-fi.

Xenoarch is a system for dynamic artifacts that do .. weird things, really.

More importantly, the system allows players to find, discover, and *exploit* the artifacts. Artifacts going rogue from a
broken glass is fun and all - but the real fun is when players get to harvest them for energy and to do all sorts of
cool stuff.

That, and - welcome to Noita.
